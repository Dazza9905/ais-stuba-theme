## 💾 Requirements & Installation
### Prerequisites
To use this, ensure you have [Violentmonkey](https://violentmonkey.github.io/) and [Stylus](https://github.com/openstyles/stylus) installed.

### Instalation
When using the above mantioned extentions, they should auto-detect the folowing links and prompt you to install the theme/scripts
You will be able to easily update it with the extention without copy-pasting every update :)
[Install Userscript](https://raw.githubusercontent.com/Dazza9905/ais-stuba-theme/main/script.user.js)
[Install Userstyle](https://raw.githubusercontent.com/Dazza9905/ais-stuba-theme/main/style.user.css)
